## Новые баги, найденные и исправленные в ходе рефакторинга

1. **Цикл `Для Инд = Массив.ВГраница() По 0 Цикл` не выполнялся ни разу** —
   в 1С цикл `Для…По` только инкрементирует счётчик. Извлечение номера дома было
   сломано дважды (вместе с багом 1.1). Заменено на `Пока`.
2. **`ПолучитьРасширение("a.b.docx")` возвращала `"bdocx"`** — расширение
   резалось от первой точки с удалением всех точек. Теперь — от последней точки.
3. **Запись реквизита в ссылку/в уже записанный объект** в банковском блоке
   `CREATE_SET_GET_ФизЛицоНаСервере` (строки 1348, 1352 исходника):
   `нКонтрагент.ОсновнойБанковскийСчет = …` выполнялось либо на ссылке (ошибка
   времени выполнения), либо на объекте после `Записать()` (изменение терялось).
   Теперь счёт записывается через `ПолучитьОбъект()`/`Записать()`.
4. **SQL-инъекция в автоподборе адресов**: текст пользователя конкатенировался
   в текст запроса (`ПОДОБНО "%" + Текст + "%"`). Теперь передаётся параметром.
5. **`СохранитьФайлВСправочник` падал при пустом договоре**: безусловное
   `Объект.ДоговорКонтрагента.Владелец.Ссылка` затирало ранее заполненного
   контрагента и падало на пустой ссылке. Контрагент передаётся параметром.
6. **Скан паспорта пересохранялся при чтении**: блок сохранения файла выполнялся
   в GET-функции поиска паспортных данных. Сохранение оставлено только при
   создании записи регистра.
7. **`ОтветственноеЛицоЗаДоставку` контрагента заполнялось контактным лицом
   вместо адреса/лица из документа** — сохранено поведение, но без затирания
   пустыми значениями (итоговая дозапись только при найденном контрагенте).
8. Уведомление «Записано!» показывалось **до** записи (в `ПередЗаписью`) даже
   если запись не прошла — перенесено в `ПослеЗаписи`.
9. `GET_ДействующийОткрытыйДоговор` возвращал то `""`, то строку — теперь
   возвращает ссылку либо `Неопределено`, сообщение выводит вызывающий код.
10. Флаг `ЗаписьВключена()` (всегда `Истина`) удалён — половина записей шла
    мимо него, создавая ложное ощущение управляемости.

## Что осталось за рамками (осознанно)

- Склонение ФИО по-прежнему через `C:\proj\morfer2.rb` и общий файл
  `C:\proj\morfer.txt` — гонка при одновременной работе двух пользователей
  осталась (нужен сервис склонения; помечено TODO).
- Бизнес-логика по-прежнему в модуле формы — перенос в общий модуль требует
  доступа к конфигурации (помечено TODO в шапке модуля).
- Захардкоженные наименования справочников сведены в одну область, но не
  заменены на предопределённые элементы (требует изменения конфигурации).
